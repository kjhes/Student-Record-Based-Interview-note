# 생기부 면접노트

2027 수시 면접 준비용으로 만든 한 페이지짜리 노트입니다. 학교생활기록부 문장마다 예상 질문을 달고, 문단 단위로 답변을 쓰고, 꼬리질문까지 정리합니다.

## 기능

- 학년·영역별 생기부 문장 보기, 문장별 질문 만들기
- 문단 전체를 옆에 두고 질문에 답변 쓰기 (메모장 패널, 형광펜, Ctrl/⌘+Z 되돌리기)
- 꼬리질문, 꼬리의 꼬리질문 직접 추가
- AI 답변 검사, 꼬리질문 추천

## 주의

- 원래 claude.ai 아티팩트로 만든 페이지입니다. AI 검사(`window.claude` sample)와 데이터 저장(db)은 claude.ai 안에서만 동작합니다. 이 저장소의 `index.html`을 그냥 열면 화면은 보이지만 저장된 질문·답변과 AI 기능은 없습니다.
- 질문·답변 데이터는 이 저장소에 들어 있지 않습니다.
